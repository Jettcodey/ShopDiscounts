# Shop Discounts

> [!WARNING] 
> Source-Available aka "Read-Only" source code repository.

When the shop loads a discount is rolled and applied to all items put into the Shop Extraction Point.

The Discount percentage is shown on the extraction next to the money left after purrchase.

### Custom Discount
| Option | Description |
|---|---|
| Enable Custom Discount | Skip rolling and always use a fixed discount. |
| Discount Percentage | The fixed discount perccentage to use when the above is enabled. |

### Chances
These are **weights**, not percentages. Higher Value numbers means the get rolled more often.

| Option | Default Value |
|---|---|
| 0% Discount Chance | 5 |
| 1-10% Discount Chance | 40 |
| 11-25% Discount Chance | 25 |
| 26-45% Discount Chance | 15 |
| 46-65% Discount Chance | 10 |
| 66-85% Discount Chance | 4 |
| 86-100% Discount Channce | 1 |
